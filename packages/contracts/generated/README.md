# Generated Types and Schemas

This directory holds generated artifacts produced from `packages/contracts/openapi.json`.

## Rules
- Do not edit generated files manually.
- When `openapi.json` changes, regenerate contracts using the designated generator scripts.
- Generated TypeScript types serve `apps/web/src/lib/api/` and `apps/web/src/features/**`.
- Generated or validated Pydantic schemas serve `apps/api/app/schemas/` and `apps/ai/clinsync_ai/`.
